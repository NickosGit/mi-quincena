- Found (F3 prep): tesseract.js defaults to PSM 6 (single block). On the clean fixture that garbled every date ("1 nov 2026" → "Lo 206", confidence 64) while still reading all 12 amounts, so it would ask the user for every date. PSM 3 (automatic layout, Tesseract's CLI default) reads 12/12 at confidence 94. Inverting the dark header did not help; cropping it did, so the culprit is layout analysis, not color. Decided: OCR runs with PSM 3, in both `scripts/ocr-fixtures.mjs` and the browser.
